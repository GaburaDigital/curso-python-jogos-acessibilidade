Aula 3 — Listas e laços for

Objetivos

  • Criar, acessar e modificar listas.
  • Usar for e range().
  • Conhecer a biblioteca random.

Pílula da aula

O que é uma "estrutura de dados", em uma frase simples: é um jeito de organizar informação para o computador usar de forma eficiente — e a lista é a primeira e mais simples delas que vamos aprender.

O que vamos ver

  • O que é uma lista.
  • Índices — e por que começam em zero.
  • append(), remove(), len().
  • Percorrer uma lista com for.
  • range().
  • Sortear com random.choice() e random.randint().

Exercícios essenciais

Exercício 1 — Inventário do herói

Crie uma lista com 3 itens iniciais de um personagem, adicione um item novo que a pessoa digitar, remova um item e imprima o inventário final numerado.

Dica

Para numerar os itens, crie uma variável contador = 1 antes do for, imprima str(contador) + ". " + item dentro do laço, e some 1 ao contador a cada volta (contador = contador + 1).

Exercício 2 — Sorteio de inimigo

A partir de uma lista de nomes de inimigos, use random.choice() para sortear qual aparece, e random.randint() para definir quantos pontos de vida ele tem. Imprima o encontro.

Dica

Você pode juntar texto e número com +, desde que converta o número para texto primeiro com str(pontos_de_vida). Por exemplo: print("Um " + inimigo_sorteado + " apareceu com " + str(pontos_de_vida) + " pontos de vida!")

Exercício 3 — Contagem regressiva do lançamento

Use for com range() para imprimir uma contagem de 10 até 1, terminando com uma mensagem de lançamento. (Sem time.sleep().)

Dica

range(10, 0, -1) começa em 10 e vai diminuindo de 1 em 1 até passar de 0 (sem incluir o 0) — é por isso que a contagem termina em 1, não em 0.

1. Playlist da madrugada

2. Gerador de nome de banda

3. Chamada da turma

4. Desculpa aleatória para o bug

5. Fila de bugs

6. Dado de RPG

7. Baralho embaralhado

8. Mochila com limite

9. Tabela de pontuação do torneio

10. Oráculo do commit

Sorteie uma mensagem de commit absurda a partir de listas combinadas (verbo + objeto + justificativa duvidosa), gerando uma frase diferente a cada execução.

Desafio da semana — Agenda de contatos

O que você vai construir

Uma agenda de contatos em texto, que começa com alguns nomes já cadastrados, permite adicionar novos contatos digitados por você e imprime a lista completa numerada no final.

Por que isso é interessante

É o mesmo princípio de qualquer app de contatos do celular — guardar uma coleção de informações e conseguir percorrê-la depois. Toda vez que um app mostra uma lista (contatos, mensagens, músicas), por trás tem uma lista guardando essas informações, exatamente como a que você vai construir aqui.

Requisitos mínimos

  1. Começar com uma lista de pelo menos 3 contatos.
  2. Pedir 3 novos contatos usando input().
  3. Adicionar cada um com append().
  4. Imprimir a agenda inteira numerada, um contato por linha, usando for.
  5. Mostrar no final quantos contatos existem no total.

Exemplo de execução

Um exemplo de como a conversa com o programa pode ficar:

Digite o nome do 1o novo contato: Marina
Digite o nome do 2o novo contato: Diego
Digite o nome do 3o novo contato: Sofia

Agenda de contatos:
1. Ana
2. Bruno
3. Carla
4. Marina
5. Diego
6. Sofia

Total de contatos: 6

Vá além (opcional)

  • Permitir remover um contato pelo nome.
  • Sortear um contato aleatório com random.choice() sugerindo para quem mandar mensagem hoje.
  • Guardar também o telefone em uma segunda lista paralela.
  • Ordenar a agenda em ordem alfabética com sort().
  • Imprimir só os contatos cujo nome começa com uma letra escolhida por você.

Como entregar

Arquivo agenda-de-contatos.py, publicado no seu repositório pessoal pela interface web do GitHub.

Checklist de conclusão

  • Rodou sem erro do começo ao fim.
  • Usa pelo menos uma lista, um for e um input.
  • A saída fica compreensível se lida em voz alta linha por linha.
  • O arquivo está no GitHub.

Nota de acessibilidade

Ao imprimir listas, prefira uma informação por linha em vez de tabelas alinhadas com espaços — leitor de tela lê linha a linha, e colunas alinhadas viram confusão. Vale como boa prática para todo mundo, não só para quem usa leitor de tela.
