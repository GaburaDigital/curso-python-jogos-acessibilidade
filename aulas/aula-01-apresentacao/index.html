Aula 1 — Apresentação, dinâmica do curso e primeiros passos

Objetivos

  • Nos conhecermos e entender a dinâmica do curso.
  • Instalar o ambiente de programação.
  • Criar conta no GitHub e publicar o primeiro arquivo.

Pílula da aula

Por que existem tantas linguagens de programação diferentes — e por que isso não precisa assustar ninguém. Cada linguagem nasceu para resolver um tipo de problema; ao longo do curso vamos usar Python, mas as ideias que você aprender aqui (variáveis, laços, condicionais, funções) valem para praticamente qualquer outra linguagem que você venha a usar no futuro.

O que vamos ver

  • O que é um algoritmo.
  • A diferença entre hardware e software.
  • O que é uma linguagem de programação.
  • Por que Python e onde ele é usado (jogos, ciência de dados, web).
  • Como funciona a dinâmica do curso: 1h de exposição + 1h de prática, desafio semanal e portfólio no GitHub.
  • Instalação do Python 3.14 e do Thonny.
  • Criação de conta no GitHub e do primeiro repositório.

Exercícios

Não há exercício de código nesta aula. O "exercício" é o próprio processo de instalar o ambiente e criar sua conta no GitHub.

Desafio da semana

Se não deu tempo de terminar a instalação em aula, finalize em casa. Depois, escreva um pequeno texto "sobre mim" no arquivo readme.md do seu repositório pessoal, publicando a alteração direto pela interface do GitHub (sem precisar instalar nada extra).

Nota de acessibilidade

Nesta aula já testamos o Thonny junto com o Narrador do Windows, para garantir que o ambiente básico funciona bem antes de qualquer código.
