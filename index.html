Introdução à Programação com Python: Lógica, Jogos e Acessibilidade

Este curso não tenta esgotar tudo o que dá para fazer com Python — o objetivo é apresentar a linguagem, desenvolver lógica de programação e, ao longo das aulas, construir um jogo chamado Invasão Alienígena (inspirado em Space Invaders), com um modo pensado desde o início para funcionar bem para uma pessoa sem visão. O curso é para jovens a partir de 16 anos, sem exigência de conhecimento prévio de programação.

Experimente Python agora

Este é o mesmo Python que vamos usar no curso, rodando aqui no navegador só para você experimentar. A partir da Aula 1, vamos instalar o Python de verdade no seu computador.
